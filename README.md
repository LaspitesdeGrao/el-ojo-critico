# El Ojo Crítico — archivo en PDF

Los números de *El Ojo Crítico*, los cuadernos de investigación que dirige Manuel Carballal,
servidos para la biblioteca de Clave 45: https://www.clave45.com/biblioteca#el-ojo-critico

- `pdf/` — un PDF por número (`eoc-051.pdf`, `eoc-048-049.pdf` para los dobles).
- `portadas/` — la página 1 de cada número, 400 px.
- `visor/` — PDF.js 6.3.289 (legacy) de Mozilla, sin cambios, para leerlos en cualquier navegador:
  `visor/web/viewer.html?file=../../pdf/eoc-051.pdf#page=26`
